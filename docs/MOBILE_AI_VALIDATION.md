## 아직 확인하지 않은 항목

- 실제 기기의 촬영/앨범/권한 거부/딥링크/로그인/사진 업로드 통합 검증
- 실제 Supabase에 새 마이그레이션 및 모바일 반환 주소 적용
- 기존 Supabase 공개 주소는 DNS 조회에 실패했으며, 로그인 후 대시보드에는 프로젝트가 Coming up 상태로 표시됐습니다. 정상 기동 후 실제 계정 통합 검증이 필요합니다.
- 실제 모델 가중치 로드·추론·실측 대비 정확도, 모델 서버의 운영 성능
- Apple 서명 IPA, Google Play AAB, 스토어 제출 및 심사
- 운영 책임 기관의 개인정보 처리방침 확정과 실제 계정 삭제 처리 체계

AI 결과는 제작 치수에 자동 입력하지 않으며, 기존 안전 승인 조건을 변경하지 않습니다. 모델 서버가 연결되지 않았거나 감지 근거가 부족한 경우 치수를 추정하지 않습니다.
